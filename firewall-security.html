  • ▹ Stateful vs Stateless packet filtering & connection state tables
  • ▹ Zone-based security models: LAN, WAN, DMZ, VPN, Guest interfaces
  • ▹ NAT & Routing on firewalls: Source NAT, Destination NAT, 1:1 NAT, Port Forwarding

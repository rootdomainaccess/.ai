Curriculum Blueprint (4 Official Exam Domains)

Covers every domain in the AWS SAA-C03 blueprint with mechanism-level configuration.

Domain 1 · 30% of Exam

Design Secure Architectures

  • ▹ IAM Policies, Roles, Cross-Account Access & Permission Boundaries
  • ▹ Amazon VPC: Custom subnets, Route Tables, Internet Gateways, NAT Gateways & Network ACLs vs Security Groups
  • ▹ Secure hybrid connectivity: AWS Site-to-Site VPN, Direct Connect, and Transit Gateway
  • ▹ Data encryption in transit and at rest using AWS KMS (Customer Managed Keys) & Secrets Manager
Domain 2 · 26% of Exam

Design Resilient Architectures

  • ▹ Multi-AZ and Multi-Region high availability patterns
  • ▹ Auto Scaling Groups (ASG) with Application Load Balancers (ALB) and Network Load Balancers (NLB)
  • ▹ Decoupled event-driven systems using Amazon SQS (FIFO/Standard), SNS & EventBridge
  • ▹ Disaster Recovery strategies: Backup & Restore, Pilot Light, Warm Standby, Multi-Region Active-Active
Domain 3 · 24% of Exam

Design High-Performing Architectures

  • ▹ Compute selection: EC2 instance families (compute, memory, storage optimized), Lambda & ECS Fargate
  • ▹ Storage tiers: S3 Standard, S3 Intelligent-Tiering, Glacier Flexible/Deep, EBS gp3/io2, EFS & FSx for Lustre
  • ▹ Database architectures: Amazon RDS Multi-AZ, Read Replicas, Aurora Serverless & DynamoDB Global Tables
  • ▹ Edge acceleration: Amazon CloudFront CDN, Route 53 latency/geo routing, and AWS Global Accelerator
Domain 4 · 20% of Exam

Design Cost-Optimized Architectures

  • ▹ Pricing models: On-Demand, Savings Plans, Reserved Instances, Spot Instances & Spot Fleets
  • ▹ S3 Lifecycle rules and automated transition to archive tiers
  • ▹ AWS Cost Explorer, Budgets, and AWS Organizations Consolidated Billing
  • ▹ Serverless optimization: replacing idle compute with AWS Lambda + API Gateway

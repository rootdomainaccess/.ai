Curriculum Blueprint (4 Practical Modules)

Learn how to build AI infrastructure tools that save hours of manual ops work.

Module 1 · Foundations

LLMs & Local Model Runtimes

  • ▹ How LLMs work under the hood: Tokens, Context Windows, Temperature, and Sampling
  • ▹ Running models privately on your homelab: Ollama, vLLM, and llama.cpp GGUF quantization
  • ▹ Prompt Engineering for systems: System prompts, role definitions, and strict JSON output
  • ▹ Model APIs: OpenAI-compatible endpoints, LiteLLM proxy router & API key pooling
Module 2 · Agent Mechanics

Tool-Calling & Autonomous Loops

  • ▹ Function/Tool Calling mechanics: JSON schema definitions, model arguments & execution loops
  • ▹ Building terminal execution tools safely: Sandboxing, timeout management, non-destructive execution
  • ▹ Agent frameworks overview: Hermes Agent, Claude Code CLI, OpenCode, and Python custom loops
  • ▹ Multi-turn state management: conversation history pruning, vector memory & session persistence
Module 3 · Production IT Use-Cases

Automating Real Systems & Networks

  • ▹ Autonomous log parsing & incident triage: Wazuh SIEM alert summarizer & Slack/Telegram alerts
  • ▹ Automated network health-checks: pinging subnet gateways, parsing `netstat`/`ss`, generating reports
  • ▹ Docker & VM manager agent: auto-restarting unhealthy containers & checking disk ceilings
  • ▹ Automated compliance & CVE scanner: querying Trivy, comparing installed packages against CVE feeds
Module 4 · Governance & Security

Agent Guardrails & Human-in-the-Loop

  • ▹ Preventing runaway agents: loop iteration caps, token limits, and rate limiters
  • ▹ Guardrails & PII redaction: preventing accidental leakage of enterprise credentials or user data
  • ▹ Human-in-the-Loop (HITL) approval workflows for critical write operations (e.g. deleting volumes)
  • ▹ Deploying agents as systemd background services and Docker containers with health checks

Curriculum Blueprint (6 Official Exam Domains)

Fully aligned with Cisco's 200-301 blueprint, augmented with real enterprise troubleshooting methodologies.

Domain 1 · 20% of Exam
Network Fundamentals
  • Role of Routers, Layer 2/3 Switches, Next-Gen Firewalls & Access Points
  • 2-Tier, 3-Tier Enterprise Campus Architectures vs Spine-Leaf Topologies
  • Copper (Cat5e/6/6a), Single-mode & Multi-mode Fiber, PoE standards (802.3af/at/bt)
  • IPv4 Subnetting (VLSM, CIDR, Network/Host boundary math) & IPv6 Address Types (Global Unicast, Unique Local, Link-Local)
  • Virtualization fundamentals: Hypervisor Type 1 (ESXi) vs Type 2, Containers (Docker) & Virtual Switches
  • Wireless RF principles: 2.4GHz vs 5GHz/6GHz channels, RSSI, SNR, SSID & Basic Service Sets
Domain 2 · 20% of Exam
Network Access & Layer-2 Switching
  • VLAN Configuration, Access Port assignments & 802.1Q encapsulation
  • Trunking protocol, Native VLAN security risks & Allowed VLAN pruning
  • Layer 2 Discovery Protocols: CDP (Cisco Discovery Protocol) & LLDP
  • EtherChannel (Link Aggregation): LACP (802.3ad), PAgP, and static bundle modes
  • Spanning Tree Protocol (STP 802.1D, Rapid PVST+ 802.1w): Root bridge election, PortFast, BPDU Guard
  • Cisco Wireless Architecture: Lightweight APs (LWAP), Wireless LAN Controllers (WLC), CAPWAP tunneling & GUI WLAN setup
Domain 3 · 25% of Exam
IP Connectivity & Routing Architecture
  • Routing Table internals: Administrative Distance (AD), Metric calculation, Longest Prefix Match
  • IPv4 & IPv6 Static Routing: Next-hop IP, Exit Interface, Default Static (0.0.0.0/0) & Floating Static backup routes
  • Inter-VLAN Routing: Router-on-a-Stick (802.1Q sub-interfaces) vs Layer-3 Switch Switch Virtual Interfaces (SVI)
  • Single-Area OSPFv2 Deep Dive: Router ID, Hello/Dead timers, Neighbor states (Down to Full), DR/BDR election
  • OSPF LSDB, Link State Advertisements (Type 1 & Type 2), cost metric tuning & passive-interface configuration
  • Diagnosing routing loops, split-horizon rules, and black-hole route resolution
Domain 4 · 10% of Exam
IP Services & Operations
  • Inside Source NAT: Static 1:1 NAT, Dynamic Pool NAT & Port Address Translation (PAT / NAT Overload)
  • NTP (Network Time Protocol) client/server synchronization & stratum hierarchy
  • DHCP Server configuration, DHCP Client behavior, DORA process & IP Helper Address (DHCP Relay)
  • DNS operation, name resolution and caching inspection
  • SNMPv2c vs SNMPv3 (AuthNoPriv, AuthPriv with SHA/AES) & Syslog logging levels (0-7)
  • Quality of Service (QoS): Per-Hop Behavior (PHB), Classification, Marking (DSCP/CoS), Queuing (LLQ, CBWFQ), Policing vs Shaping
  • Remote access protocols: SSHv2 key generation vs Telnet deprecation, SCP/TFTP/FTP backups
Domain 5 · 15% of Exam
Security Fundamentals & Layer 2 Hardening
  • Threat landscape: Social Engineering, MITM, DDoS, Spoofing, Malware & Zero Trust principles
  • Password security: Type 0, 5 (MD5), 7, 8, 9 (Scrypt) encryption & local user privilege levels
  • Standard & Extended IPv4 Access Control Lists (ACLs): Sequence numbering, wildcard masks, established keyword
  • Layer-2 Security: Port Security (Static, Dynamic, Sticky MAC, Violation modes: Protect, Restrict, Shutdown)
  • DHCP Snooping & Dynamic ARP Inspection (DAI) against ARP poisoning/cache spoofing
  • AAA Concepts (Authentication, Authorization, Accounting) via TACACS+ and RADIUS
  • IPsec VPN Fundamentals: IKE Phase 1 (ISAKMP) / Phase 2 (IPsec SA), ESP, AH, Diffie-Hellman groups
Domain 6 · 10% of Exam
Automation & Network Programmability
  • Traditional CLI-based Management vs Controller-Led Software Defined Networking (SDN)
  • Control Plane vs Data Plane vs Management Plane separation
  • Overlay, Underlay & Fabric architectures (Cisco DNA Center / Cisco Catalyst Center)
  • RESTful APIs: HTTP Verbs (GET, POST, PUT, DELETE, PATCH), Status Codes (200, 201, 400, 401, 403, 404, 500)
  • Data Serialization Formats: Reading, validating and structuring JSON, YAML & XML payloads
  • Configuration Management Tools comparison: Ansible (Agentless / Push), Puppet & Chef (Agent-based / Pull)
  • Python network scripting basics with Netmiko and RESTCONF/NETCONF concepts

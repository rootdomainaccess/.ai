Curriculum Blueprint (RHCSA EX200 & RHCE EX294)

Structured for engineers who need to manage production enterprise fleets, not just pass a multiple-choice quiz.

Module 1 · Core Systems

Essential Tools & User Security

  • ▹ Shell manipulation: pipes, redirection, grep/sed/awk basics, vim efficiency
  • ▹ User & group management, password aging (`chage`), sudoers configuration
  • ▹ POSIX permissions, SUID, SGID, Sticky Bit & Access Control Lists (`getfacl`/`setfacl`)
  • ▹ SSH key generation, config files, disabling password auth & bastion configurations
Module 2 · Operation & Boot

Operating Running Systems & systemd

  • ▹ GRUB2 boot process, emergency/rescue targets & root password reset procedure
  • ▹ systemd unit files, targets, timer units (systemd timers vs crontab)
  • ▹ Process monitoring: `top`, `ps`, `kill`, nice/renice priority tuning, system load metrics
  • ▹ Journald logging persistence, rsyslog rules & logrotate policies
Module 3 · Storage Architecture

LVM, Filesystems & Advanced Storage

  • ▹ MBR vs GPT partitioning with `fdisk`/`gdisk`/`parted`
  • ▹ Logical Volume Management (LVM): PV, VG, LV creation, online resizing, snapshots
  • ▹ XFS vs Ext4 filesystems, persistent mounting with UUID in `/etc/fstab`
  • ▹ Stratis storage management & VDO deduplication/compression
  • ▹ Network storage: NFS client mounts & autofs automatic on-demand mounting
Module 4 · Hardening & Network

SELinux, firewalld & Networking

  • ▹ NetworkManager CLI (`nmcli`), bonding, teaming & static routing
  • ▹ SELinux Modes (Enforcing, Permissive, Disabled), Contexts (`semanage`, `restorecon`)
  • ▹ SELinux Booleans (`getsebool`/`setsebool -P`) & audit log troubleshooting (`audit2why`)
  • ▹ `firewalld` zone configuration, rich rules, port forwarding & masquerading
  • ▹ Software management with DNF/YUM, custom repo creation & AppStreams
Module 5 · Containers

Podman & Rootless Containers

  • ▹ Podman vs Docker architecture (daemonless, rootless containers)
  • ▹ Containerfile creation, building container images, registry authentication
  • ▹ Persistent volume mounts, SELinux container labels (`:Z`, `:z`)
  • ▹ Generating systemd unit files from Podman containers (`podman generate systemd`)
Module 6 · Automation (RHCE)

Ansible Automation Engine

  • ▹ Ansible architecture: Control node, managed nodes, inventory files & variables
  • ▹ YAML syntax, writing idempotency-verified Playbooks & tasks
  • ▹ Core modules: `dnf`, `systemd`, `user`, `firewalld`, `copy`, `template` (Jinja2)
  • ▹ Ansible Vault for encrypting sensitive passwords & tokens
  • ▹ Structuring reusable Ansible Roles and Collections
